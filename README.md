# Student Grade Tracker

A simple Java console-based application to manage and analyze student grades.

## Features

- Add student names and marks
- Display all student grades
- Calculate average marks
- Find the highest marks
- Find the lowest marks
- Display the student with the highest and lowest marks

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Scanner

## How to Run

1. Clone or download the repository.
2. Compile the Java files:
   javac Student.java StudentGradeTracker.java
3. Run the program:
   java StudentGradeTracker
